## Why even the subtraction-framed public surface dies

The designer's cleverest move was inverting the primary key: the Liberty Ledger's unit of account is an **externally-verifiable subtraction event that exists independent of Cato** (a repeal on the books, a court order, a zeroed appropriations line), with Cato only a foreign-key attribute — so "you cannot assemble a *Cato wrote N laws* file from a table whose rows are the state shrinking." The panel granted that this **repairs the data model** but ruled it **does not repair the goal**:

- **The dispositive strike (Munger F16, escalated by Meadows + Socrates), on the spec's own logic:** the honest configuration (misses-first, no aggregate, mostly-losing, safe lanes duplicating the Record's judicial receipts) delivers **near-zero external and donor-legible value**, while every *fundable* configuration ("Cato shrank N laws") is explicitly forbidden — so the **only remaining reason to publish is perception management**: the §10 influence-showcase in libertarian costume.
- **The cause (Meadows F33):** the state remains the reference frame; the key-inversion is cosmetic to the *goal*.
- **The mechanism (Taleb F1):** a public trophy is a convex option-harvester, bending 18–36 months of effort toward overdetermined, winnable teardowns.
- **The consequences (Sun Tzu F24/25/26; Machiavelli F7):** a self-authenticated adversary target-map, a pre-sorted oppo file whose non-enumerability binds only Cato, and a published kill-list whose mandatory `counterfactual_note` becomes the hostile pull-quote.

**Internal-defensive use, by contrast, every frame conceded genuinely useful** — it severs the donor/press/prestige feedback loop, erases the adversary target-map, and leaves the irreducible frame-capture prior *tolerable rather than dissolved*, because the tool no longer answers "what are we worth?" Hence **internal-only, not kill** — the same §10→§11 trade that earned the barbell its pass.

## What folds into v0.4

- **Fatal:** demote the Liberty Ledger to internal, counsel-gated, curatable; no public page.
- **Core-governance (serious):** build out §8 — an independent panel with *structural* independence (external appointment, escrowed funding, non-Cato secretariat, staggered non-renewable terms, public conflict register, removal Cato can't initiate) and **separation of powers** (certification / enforcement / attribution-grading + a thin meta-audit), with the most consequential kill-triggers **auto-executing** (panel holds veto-with-reasons) so a captured or slow panel can't silently withhold the brake.
- **Core-gate (serious):** harden the external-demand gate — ≥3 *distinct, unaffiliated* unprompted citations, seeded-vs-organic tracked, adversarial framing ("bill-mill/teardown-shop" press, hostile-AG interest) counted as a **KILL signal**, panel-certified rather than self-certified.
- **Barbell (serious):** brand-separate the protected axiom pole so it can't inherit the Record's court-earned credibility by adjacency.
- **Legal (serious):** widen the §0 counsel gate to *every* legislative-position lane; only pure judicial lanes carry the "external forum is scorekeeper" defense.
- **Internal-tool mechanics (serious):** base-rate gate, mandatory substitution-check (net offsetting enactments before counting a repeal), panel-certified *substantive adoption* for court citations, SUNSET/REPEALED default to uncounted, durability seasoning across an administration turnover, hard arena-capture gauge; drop the word **"helped"** (an attribution claim in foreign-key costume).

## The until-condition: asymptotic, not reachable

The chairman set `untilCondition: asymptotic-grudging-only` and `residualAreIrreducible: true`. Full conviction of the *most hardcore* libertarian is unachievable by any design; the ceiling is grudging worth-pursuing under permanent suspicion. The irreducible priors: (1) the state as economic scorekeeper; (2) state courts as arbiters — sharpened here, because `VACATED`/court-adoption receipts *celebrate* a state organ's power rather than merely submit to it; (3) a centrally-authored rulebook; (4) the subtraction frame still makes the state the reference frame, "liberty denominated in the state's own units"; and (5) the deepest — the greatest libertarian victory (an idea so absorbed no law cites it) is scored **zero by any registry, public or internal**, and building the registry creates the pull toward the countable regardless of visibility. *The honest terminal state of a maximally-successful Liberty Ledger is an empty page.*
